LifeLens – Multimodal Emotion Detection System

2025

LifeLens is an advanced AI-driven system designed for real-time emotion recognition by fusing multiple data modalities, including facial expressions, voice tone, and textual input. Leveraging deep learning architectures such as convolutional neural networks (CNNs) for visual features and recurrent models for audio-text sequences, the project achieved robust classification across emotions like happiness, anger, sadness, and surprise.

SmartSplit – Intelligent Expense Management Application

2025

SmartSplit is an AI-powered mobile/web application that automates personal and group expense tracking, categorization, and bill splitting. Utilizing machine learning models (e.g., supervised classification for transaction labeling and predictive analytics for spending forecasts), it processes receipts via OCR, detects patterns in user data, and suggests fair splits among groups.

IVAMS – Intelligent Vehicle Automation and Monitoring System
